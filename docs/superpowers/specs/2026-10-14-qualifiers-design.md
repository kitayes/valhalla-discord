# Турнир: квалификации, нижняя сетка, формат BO, чекин

Дата: 2026-10-14
Статус: согласовано, ждёт плана реализации

## Зачем

Сезон идёт так: две квалификации, из каждой выходит 8 команд, плюс
приглашённые команды — вместе они играют основной этап. Сейчас бот этого не
знает:

- квала доигрывается до финала: после 1/8 четвертьфиналы в Challonge открыты,
  и мини-апп показывает их LIVE, хотя квала уже кончилась;
- нет понятия «прошла в основу» и «приглашённая команда»;
- формат BO захардкожен в трёх местах с разной логикой, BO5 нет, на карточке
  матча формат не виден;
- сетки бывают с нижней сеткой (double elimination), а конец квалы, места и
  форматы считаются только для олимпийки;
- команда прошла чекин, но получила техническое поражение.

## Что получится

### Этапы

У турнира появляется `stage`:

- `qualifier` — квалификация. `advance_count` (по умолчанию 8) — сколько
  команд выходит дальше;
- `main` — основной этап. Участники: прошедшие из выбранных квалификаций и
  приглашённые. Капитаны сами не заявляются;
- `standalone` — обычный турнир, как сейчас. Все существующие турниры
  становятся `standalone`.

Запись команды в турнире получает `source` (`registered` | `qualified` |
`invited`) и `qualified_from` (id квалы).

Команда со статусом `qualified` в одной квале не может заявиться (и не
заявляется автоматически при чекине) в другую квалу. Админ может её
пригласить куда угодно.

### Где кончается квала

Квала кончается, когда в ней осталось `advance_count` живых команд. Живая —
та, что проиграла меньше, чем нужно для вылета (1 матч в олимпийке, 2 в
double elimination). Сыгранными должны быть все матчи «раундов отсечения»:

`size` — ближайшая степень двойки ≥ числа участников, `A` = `advance_count`
(степень двойки, ≥ 2 для олимпийки, ≥ 4 для double elimination).

- Олимпийка: играются раунды `1..c`, `c = log2(size / A)`.
- Double elimination: верхняя сетка `1..u`, `u = log2(2·size / A)`; нижняя
  `-1..-l`, `l = 2u − 2`. После этого живы `A/2` команд верхней и `A/2`
  нижней.
- Если `c ≤ 0` (или `u ≤ 1`) — участников не больше `A`, проходят все.

Матчи дальше отсечения остаются в Challonge, но не попадают в локальный кэш
квалы: их нет в мини-аппе, в «Моём матче» и в уведомлениях капитанам.

Проверка на целостность: после отсечения число живых должно быть ровно `A`.
Если нет (нестандартная нумерация раундов Challonge), квала не закрывается
автоматически, админам уходит сообщение, закрыть можно кнопкой.

Закрытие квалы — автоматически после синка, когда сыгран последний матч
отсечения, или кнопкой админа «Завершить квалификацию» (нужна для уже
прошедшей квалы #1). Закрытие:

- живые команды получают статус `qualified`;
- матчи за отсечением удаляются из кэша;
- турнир → `completed`, `is_active = false`, глобальные настройки Challonge и
  время турнира очищаются, чтобы фоновый воркер больше не трогал эту сетку;
- в турнирный чат: «Квалификация завершена. В основной этап прошли: …».

Очков лиги квала не даёт.

### Основной этап

Админ в мини-аппе:

- «Добавить прошедших» — выбирает завершённые квалы, их `qualified` команды
  записываются с `source = qualified`, `qualified_from = <квала>`;
- «Пригласить команду» — на карточке команды в админ-панели, если активный
  турнир `main` и команда в нём не записана: `source = invited`.

Дальше всё как обычно: чекин, сетка, матчи.

### Нижняя сетка

Double elimination поддерживается везде, где сейчас неявно предполагается
олимпийка:

- конец квалы — см. выше;
- места при завершении турнира: место команды = 1 + число команд, живых после
  раунда, в котором она вылетела. Олимпийка: 1, 2, 3–4, 5–8…; DE: 1, 2, 3, 4,
  5–6, 7–8, 9–12…. Очки лиги по месту: 1 → 100, 2 → 70, 3–4 → 50, 5–8 → 20,
  9–16 → 10, остальные → 5;
- названия раундов: «Верхняя сетка, Раунд N», «Финал верхней сетки», «Нижняя
  сетка, Раунд N», «Финал нижней сетки», «Гранд-финал»;
- `Reinstate` («вернуть команду») ищет матч, в котором команда вылетела, с
  учётом двух поражений.

### Формат BO

У турнира три настройки, каждая 1, 3 или 5:

- `format_rounds` — обычные раунды (по умолчанию 1);
- `format_semifinal` — полуфинал (по умолчанию 3);
- `format_final` — финал (по умолчанию 3).

Одна функция `MatchFormat(турнир, матчи, раунд)`:

- квала: раунды отсечения → `format_final` («решающий раунд»), остальные →
  `format_rounds`;
- олимпийка: последний раунд → финал, предпоследний → полуфинал;
- DE: гранд-финал → финал; финал верхней и финал нижней сетки → полуфинал;
- round robin, swiss → `format_rounds`.

Формат виден на каждой карточке матча (плашка `BO3`), в заголовке раунда, в
модалке матча, в «Моём матче» и в уведомлении «матч готов». Над сеткой —
плашка этапа: «Квалификация», «Основной этап».

Счёт капитана проверяется по формату: победитель набрал `(n+1)/2`, проигравший
меньше. Техпобеда по умолчанию — `(n+1)/2 : 0`.

### LIVE

LIVE — только открытый матч активного турнира. В завершённом турнире открытые
матчи показываются как «НЕ СЫГРАН». Без активного турнира кэш сетки пуст (сейчас
он отдаёт матчи всех турниров разом).

### Чекин

Вероятная причина жалобы: чекин — переключатель. Капитан отмечался в боте
(`/checkin` или кнопка напоминания), мини-апп об этом не знал и показывал «НЕ
ПОДТВЕРЖДЕНО»; нажатие там **снимало** чекин, и в T+10 команда получала
техпоражение. Повторный `/checkin` тоже снимал.

Изменения:

1. Чекин ставит явное состояние. API: `POST /api/team/checkin
   {"checked_in": true|false}`, ответ — фактическое состояние. `/checkin` в
   боте только подтверждает, `/uncheckin` — снимает. Повторное действие ничего
   не меняет.
2. Чекин закрывается на старте турнира или при построении сетки, что раньше.
   После этого менять его может только админ.
3. Проверка «5 игроков» считает только основной состав — как сетка.
4. Чекины из бота тоже рассылают SSE `checkin_update`; мини-апп
   перезагружает профиль при возвращении на вкладку.
5. Запись команды в турнире хранит `checked_in_at` и `checked_in_by`
   (telegram id или 0 для админа) — по следующей жалобе видно, кто и когда.
6. `/checkin_status` читает записи активного турнира.

### Сетка строится из отметившихся

Сейчас сетка строится за час до старта из всех заявленных, неотметившиеся в
T+10 получают техпоражение, и их соперники проходят без игры.

Новое: в момент старта (T) бот строит сетку **только из команд с чекином**.
Заявленные без чекина получают статус `no_show`, сообщение «Команда не прошла
check-in и не попала в сетку», админам — список. Отдельной волны техпоражений
в T+10 больше нет. Ручной старт админом из мини-аппа работает так же.
Напоминание за 30 минут остаётся, текст — «иначе команда не попадёт в сетку».

## Данные

Миграция `000034_tournament_stages`:

```sql
ALTER TABLE telegram_tournaments
    ADD COLUMN stage VARCHAR(16) NOT NULL DEFAULT 'standalone',
    ADD COLUMN advance_count INT NOT NULL DEFAULT 0,
    ADD COLUMN format_rounds SMALLINT NOT NULL DEFAULT 1,
    ADD COLUMN format_semifinal SMALLINT NOT NULL DEFAULT 3,
    ADD COLUMN format_final SMALLINT NOT NULL DEFAULT 3;

ALTER TABLE telegram_tournament_teams
    ADD COLUMN source VARCHAR(16) NOT NULL DEFAULT 'registered',
    ADD COLUMN qualified_from INT REFERENCES telegram_tournaments(id) ON DELETE SET NULL,
    ADD COLUMN checked_in_at TIMESTAMPTZ,
    ADD COLUMN checked_in_by BIGINT;
```

Статусы записи: `registered`, `checked_in`, `disqualified`, `qualified`,
`no_show`.

## Админка (мини-апп)

- Создание турнира: этап, сколько выходит (для квалы), три формата BO.
- Новая кнопка «Настройки» у турнира — те же поля для существующего турнира
  (`POST /api/admin/tournament/update`); этап и `advance_count` нельзя менять
  после завершения.
- «Завершить квалификацию» (`POST /api/admin/tournament/finish` для квалы
  ведёт себя так; при незавершённых матчах отсечения — ошибка со списком).
- «Добавить прошедших» (`POST /api/admin/tournament/import-qualified`).
- «Пригласить» на карточке команды (`POST /api/admin/tournament/invite`).

## Порядок для квалы #1 после выкладки

1. Админ: «Настройки» квалы #1 → этап «Квалификация», выходят 8.
2. «Завершить квалификацию» → 8 команд `qualified`, четвертьфиналы исчезают.
3. Создать квалу #2 (этап «Квалификация»), дальше — как обычно.
4. После квалы #2: создать основной этап, «Добавить прошедших» из обеих квал,
   пригласить команды.

## Не входит

- Сетка по группам, round robin / swiss для квал.
- Очки лиги за квалы.
- Удаление матчей за отсечением в самом Challonge.
