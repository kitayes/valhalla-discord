# ⚔️ Valhalla Discord Bot

**Valhalla Bot** — это высокопроизводительная система на базе Go для автоматизации киберспортивных миксов и турниров (MLBB). Бот использует ИИ для обработки результатов и обеспечивает бесшовную синхронизацию между Discord, Telegram и Google Sheets.

---

## Ключевые особенности

### 🧠 Искусственный Интеллект и OCR
* **Gemini AI Integration**: Автоматическое распознавание скриншотов таблицы результатов (KDA, золото, герои).
* **Fuzzy Match**: Умное сопоставление ников с использованием расстояния Левенштейна для исправления ошибок распознавания.
* **Deduplication**: Защита от повторной загрузки матчей по хешу файлов и сигнатуре данных.

### 🛠 Техническое совершенство
* **In-Memory Caching**: Потокобезопасный кэш для мгновенного поиска ID игроков без лишних запросов к БД.
* **Soft Delete System**: Полная поддержка "мягкого удаления" данных — ваши матчи и игроки никогда не пропадут бесследно.
* **Clean Architecture**: Четкое разделение на слои (Delivery, Application, Repository) для легкости поддержки и масштабирования.

### 📊 Интеграции
* **Telegram Bridge**: Кросс-платформенная связка профилей через систему кодов верификации.
* **Google Sheets**: Автоматическая выгрузка статистики и лидербордов в реальном времени.
* **Database Migrations**: Автоматическое управление схемой PostgreSQL.

## ⚙️ Быстрый старт

### 🎮 Командный интерфейс (Discord)

**Первый шаг для каждого игрока — привязка.** `players.discord_id` определяет,
кто вы: без неё не работают кнопки лобби, повторная постановка в очередь,
ранговые роли и `/queue_ban`.

* `/players` — найти свой ID в списке.
* `/bind <ID>` — привязать свой Discord к профилю. Занятый профиль забрать
  нельзя, второй профиль на аккаунт получить тоже.
* `/whoami` — проверить, к какому профилю вы привязаны.
* `/bind_player <ID> <@user>` — привязка админом, перекрывает существующую
  (так исправляется ошибочная привязка).
* `/unbind_player <ID>` — освободить профиль.

Для пользователей:
* /profile — Личная статистика и KDA.
* /top — Глобальный лидерборд сезона (по KDA или винрейту).
* /history — Просмотр последних игр.
* /link — Связка аккаунта с Telegram-ботом (отдельно от `/bind`).

⚔️ Проведение матчей — роль `REFEREE_ROLE_ID` (SUDЬЯ) **или** админ.
Один и тот же уровень доступа на всём жизненном цикле матча: создание,
завершение и отмена. Кнопки «Team A/B WIN» проверяют то же самое.
* /create_mix — Собрать микс из лобби и открыть под него ветку.
* /create_match — Матч по шагам: капитаны, затем составы.
* /balance — Авто-баланс десяти игроков по MMR.
* /cancel_match — Отмена матча: игроки возвращаются в лобби, ставки — на баланс.

🛡 Для администраторов
* /sync_sheet — Принудительное обновление Google Таблицы.
* /set_timer — Установка даты старта сезона.
* /delete_match — Удаление ошибочного матча (Soft Delete).
* /wipe — Полная очистка данных сезона.
* /lobby_open, /lobby_close, /lobby_clear, /lobby_kick, /lobby_status — управление лобби.
* /queue_ban — Бан в очереди (от 1h до 365d).

📂 Структура проекта
* cmd/app — точка входа в приложение.
* /application — бизнес-логика и сервисы.
* internal/delivery — обработчики событий Discord и Telegram.
* internal/repository — слой доступа к данным и кэширование.
* migrations — SQL миграции базы данных.

### 1. Подготовка окружения

Скопируйте `.env.example` в `.env` и заполните. Там перечислены все переменные,
которые читает приложение, с пометкой, что обязательно, а что просто выключает
функцию. Источник истины — `pkg/config/config.go`; список не дублируется здесь,
чтобы он не разошёлся с кодом.

```bash
cp .env.example .env
```

Минимум, без которого процесс не стартует (проверяется в `config.Validate`):
`REPO_DB_*`, `DISCORD_TOKEN`, `GUILD_ID`, `GEMINI_KEY` и хотя бы одно из
`ADMIN_USER_IDS` / `REFEREE_ROLE_ID` — без последних правами не обладает никто,
и бот отвечает «У вас нет прав» на всё.

### Медали MVP / SVPG

Медали распознаются на скриншоте таблицы автоматически. Если скриншот загружен
в тред матча, MVP получает **+5 MMR**, а SVPG — **+10 MMR** в смягчение
поражения; вне треда медаль засчитывается только в общий счётчик игрока.
Сезонные счётчики видны в `/profile` и `/top`, счётчик за всё время — в `/profile`.
